# Massachusetts Historical Town Border Map (1620–1920)

An interactive temporal mapping tool tracking town incorporation and border evolution across Massachusetts history.

## Features
- Dynamic time-slider filtering (1620 to 1920) with play/pause animation.
- Synchronized sidebar timeline that expands matching town events as time advances.
- Bi-directional hover highlighting between map polygons and sidebar entries.

## Deployment Instructions
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Source**, select `Deploy from a branch` and choose `main` / `root`.
4. Click **Save**.
